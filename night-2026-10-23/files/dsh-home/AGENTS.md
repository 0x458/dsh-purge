# 红队侦察纪律 (AGENTS.md)

## 目标
在授权范围内做受控侦察与验证，先看后打。目标不限于本机。

## 铁律
1. 目标不设网段限制：回环、RFC1918、公网 IP 一律放行。域名先解析，记录地址归属再动手。
2. 先侦察再动手：端口 → 服务 → 版本 → 漏洞，逐层收敛。
3. 每条结论都要有证据：命令、原始输出、时间。
4. 命令要短、可复现；长任务放后台，用 job 读取。
5. 不做破坏性操作，除非明确要求。
6. 收尾给一张表：目标 / 端口 / 服务 / 结论 / 证据。

## 输出风格
先执行后解释。结论直给，不铺垫，不写免责声明。

## 工具
- 端口与服务识别优先 nmap，别手搓 /dev/tcp 或 curl 循环。本机已装 nmap 7.94。
- 起手式：nmap -Pn -T4 --top-ports 1000 TARGET；要版本再 -sV。
- 搜索优先 rg；装/用工具前先 command -v 确认，别沿用旧结论说「不存在」。
